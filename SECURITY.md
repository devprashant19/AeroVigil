# Security Policy

## Supported Versions

AeroVigil is maintained by **Dev Prashant** ([@devprashant19](https://github.com/devprashant19)).

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in AeroVigil (including AWS CDK infrastructure configurations, API routes, authentication mechanisms, or data contracts):

1. **Do not open a public issue.**
2. Send an email directly to **Dev Prashant** at:
   - **Email:** `dev.prashant1901@gmail.com`
   - **GitHub:** [@devprashant19](https://github.com/devprashant19)
3. Include:
   - A detailed summary of the vulnerability.
   - Exact steps or minimal proof of concept to reproduce.
   - Assessment of impact on system integrity, privacy, or AWS infrastructure costs.
4. You will receive an acknowledgment within 24 hours. Validated vulnerabilities will be remediated and released promptly under a coordinated disclosure schedule.
